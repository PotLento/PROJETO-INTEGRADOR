# Protótipo Web: Controle de Horas Extras

## Sobre o Projeto

Este é um protótipo de front-end para um sistema de controle de horas extras, desenvolvido para o Projeto Integrador. O objetivo foi transformar os wireframes e o design de UX/UI em um site web funcional.

O projeto foi todo construído com **HTML5** e **CSS3**, e depois refatorado para usar **Bootstrap 5** para garantir que o layout ficasse responsivo e se adaptasse a telas de celulares e computadores.

---

## O que o Sistema Faz?

O site simula a navegação de três tipos de utilizador diferentes:

* **Técnico:** Pode fazer login e consultar seu painel para ver agendamentos futuros e seu histórico de horas.
* **Encarregado:** Pode criar novas solicitações de horas extras (em um formulário de 2 passos) e ver o status dos seus pedidos (Pendentes, Aprovados, Rejeitados).
* **Gestor:** Vê um resumo de custos na sua página inicial e pode analisar as solicitações pendentes para aprovar ou rejeitar.
